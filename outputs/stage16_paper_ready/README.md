# Stage16 — Paper-Ready Evaluation

Base: Stage15B commit `2deef55128730b02c1cf0bd9e7237a23d6865133`. Work branch: `stage16/paper-ready-evaluation`. All new artifacts are confined to this directory. Stage15B's three predictors,18 heads, scores and bootstrap decisions are immutable references.

The delivery reports are [external baseline review](stage16_external_baseline_review.md), [head initialization stability](stage16_seed_stability.md), [probability quality](stage16_probability_analysis.md), [scientific summary](stage16_scientific_summary.md), and [final report](stage16_final_report.md). [Frozen result manifest](stage16_stage15b_result_manifest.json) records source SHA256 and the unchanged selected checkpoints. The final audit gates complete delivery.

Main figures1–6 and supplementaryS1/S2 are in `05_figures/`, each SVG/PDF/PNG with editable vector text. [Figure legends](05_figures/stage16_figure_legends.md) specify definitions, denominators and statistical limits. Source tables are in `06_source_data/`; small case identities/SHA and metadata are in `07_cases/`. The original local nuScenes context and exact derived case-coordinate CSVs remain local under dataset policy; no raw dataset shard is uploaded. Checkpoints, numeric caches, downloaded public code cache and logs are excluded from Git. Public literature code is pinned and can be re-fetched by `02_literature/stage16_fetch_literature_code.py` before its no-optimizer preflight.

Reproduction uses the existing `ped_intent` Python environment and RTX3080, with `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 CUBLAS_WORKSPACE_CONFIG=:4096:8`. Analysis scripts read the existing frozen Stage15B caches; they do not download or copy nuScenes. `stage16_prepare_figure_data.py` reconstructs small local plot exports from those exact caches, not from FDE summaries. `stage16_probability.py` verifies oracle labels and identities against frozen metrics. `stage16_figures.py` renders seven figures; after the head evaluation, `stage16_seed_figure.py` adds S2, then `stage16_figure_qa.py` checks all exports and sources.

Training supplement is limited to24 fresh ranking heads (four models × threefolds × two new initialization seeds), plus twelve original head results. Original sample permutations are retained to isolate initialization. No new HiVT fitting or calibration fitting is performed. The evaluator requires all24 selected heads to be frozen before Outer access. These supplementary results never replace Stage15B's preregistered seven-model results or bootstrap family.

The protocol is custom internal scene-isolated CV on nuScenes TRAIN630, with K6 and full-horizon actor windows. It is not official nuScenes test and not a pristine independent scientific confirmation set. Brain-AI review, target-journal selection and external-baseline decisions remain separate. **STOP after completed commit/push; no next stage is started.**

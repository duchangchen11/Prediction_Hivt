Batch benchmark performs three original-NLL forward/backward/AdamW steps at 4, 8 and 16 on the largest-context train windows, discards those models, and picks the largest stable size below 90% PyTorch reserved memory. Final input/network dimensions, dropout, weight decay and FP32 remain unchanged. Batches shuffle scene order and within-scene window order each epoch; every training window appears exactly once per epoch. The loader holds at most two scenes, uses zero workers and avoids global all-graph materialization.

Protocol 1 settings are written **before training** in `00_manifest/stage2c_config.yaml`. Fixed scale regression is mean absolute coordinate error, retaining original best-sum-L2 selection and classification. Warm-up LR=.001, minimum2500/maximum10000 steps, validate every500. After the minimum, five consecutive non-improving overall-FDE validations permit transition; this predeclared plateau criterion prevents extending warm-up through clear overfitting. The source warm-up checkpoint is the best **overall** validation full-horizon FDE, not the diagnostic moving checkpoint.

Original learnable Laplace NLL uses LR=.0001, the selected warm-up AdamW state and Torch CPU/CUDA RNG, no scheduler, maximum10000 steps, validation every500 and patience5. Final primary selection uses post-update NLL validation overall full-horizon FDE. Cumulative executed global steps and the selected source warm-up step are both recorded: returning to the best warm-up checkpoint intentionally rewinds weights/optimizer, rather than pretending they came from the last warm-up step. Model initialization and optimizer snapshots are fresh for formal trainval, not mini/tiny weights.

The pre-registered sampler code uses seed2022+phase-epoch for warm-up and seed2022+100000+phase-epoch for NLL. This fixed phase offset provides a new deterministic scene/window ordering. Continuous Laplace negative log-likelihood can be negative; finite gradients and validation trajectory errors are checked independently. The completed run used the pre-registered Git training version without a training interruption. After completion, resume-only recovery was tightened to discard CSV rows beyond the restored checkpoint when a crash happens between curve and checkpoint writes; this does not alter the completed run's weights, losses, configuration or selection.

Checkpoint sidecars include epoch, phase/global steps, LR, validation metrics, moving metrics, git commit/config SHA256, selection criterion and checkpoint SHA256. Warm-up/final moving checkpoints remain diagnostic. Resume reads the last completed validation snapshot, restores its sampler offset and RNG, and replays only the unsaved interval. Full VAL comparisons assert identical actor identities/horizons/states row by row. ADE follows upstream HiVT best-FDE mode convention; independent-minimum ADE is also recorded. MR is final error>2m. CV has one trajectory, HiVT six; common table columns follow the requested minADE6/minFDE6 names.

Bootstrap uses1000 paired scene resamples, pooling complete actor clusters with original actor-window weights; the same scene multiplicities weight HiVT and CV. Tests check that duplicating correlated actors does not narrow CI, that lazy loading stays bounded and returns independent clones, and that arbitrary future targets/masks cannot affect predictions.

Practical acceptance guards are predeclared: finite stable training, no scene leakage, overall full-horizon FDE<6m and moving FDE<15m. They quantify reasonable generalization and exclude validation moving FDE in the tens of meters; they do not force a CV win. Research cases use ADE and FDE together: A if overall and moving both improve on CV; B if overall improves and moving is at most15% worse on both metrics; C if both groups are clearly worse. Mixed outcomes are reported explicitly and do not automatically authorize Stage3. No model, split, horizon or actor definition is changed to obtain a preferred result.

Qualitative selection uses real t0 moving attributes and GT displacement≥5m; successes have ADE/FDE≤2m, failures FDE>2m, with distinct instances. Main figure additionally requires observed turn≥20°, FDE improvement over CV≥2m and ADE improvement≥.5m. The primary checkpoint is fixed before any visual selection. All numerical trajectories/probabilities are saved; main figure uses Python/matplotlib, 183mm width, PNG600dpi plus editable SVG/PDF. A selected example is not evidence of aggregate superiority.

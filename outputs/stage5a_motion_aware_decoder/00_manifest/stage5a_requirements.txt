============================================================
三、本轮研究问题
============================================================

研究问题：

不同类型和不同历史运动状态的交通参与者，
是否需要不同的轨迹解码映射？

当前 HiVT 使用完全共享的 MLPDecoder：

shared interaction representation
        ↓
shared aggr_embed
        ↓
shared loc / scale heads

可能无法充分适应：

moving vehicle
stopped/parked vehicle
pedestrian
bicycle

之间明显不同的运动模式。

因此提出：

Motion-Aware Heterogeneous Residual Decoder

核心原则：

1. HiVT interaction backbone 完全保持原结构。
2. TypeEmbedding 保留。
3. 不再修改 attention score。
4. 仅在 decoder hidden representation 上做轻量适配。
5. 只使用历史可观测运动信息。
6. 暂时不修改 mode probability pi head。
7. 不进入 Reliability Head。

============================================================
六、核心公式
============================================================

原 decoder：

h_ki =
Aggr(
[
global_ki,
local_i
]
)

Stage5A：

首先计算 actor-level observable condition：

c_i

然后 router：

r_i =
softmax(
Router(c_i)
)

固定：

2 个 residual experts。

每个 expert：

A_e(h)

最终：

Delta h_ki =
sum_e
r_i,e * A_e(h_ki)

然后：

h'_ki =
h_ki + Delta h_ki

使用：

h'_ki

进入：

loc head
scale head

即：

Yhat_ki =
Loc(h'_ki)

Scale_ki =
Scale(h'_ki)

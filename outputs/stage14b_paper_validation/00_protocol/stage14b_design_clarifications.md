# Stage14B 预登记设计措辞澄清

本说明在新增匹配头 OuterTest 评价前记录，只澄清命名与未来执行契约，不改变任何当前拟合结构、损失、seed、数据或统计规则。

1. 预登记中“原始HiVT评分无需头训练”指各折共同 **Stage5A结构生成器的原始模式分数（R0）**，不是未经增强的 Original HiVT 网络。真正 Original HiVT 适配器需要另加每fold一次预测器训练，共额外3次及其候选缓存；这些不包含在推荐A的3次、B的12次或18个排序头的成本中。两项核心贡献在同一生成器上的机制对照可使用R0；如论文还主张增强生成器相对原HiVT的优势，必须另行设计这项公平生成器基线。
2. B的三个内层模型和最终模型全部使用对应外层fold的固定预测器seed（2022、2122、2222之一），从同一初始化规则重新开始；内层scene集合不同，不挑seed、不做ensemble、不把12模型数称为独立seed重复。其排序头仍使用原三fold seed。
3. 本机target manifest检查结果均为不存在，完整官方tokens未经验证。未来找到文件仅证明路径存在；正式兼容核验还需要JSON结构、scene键、instance/sample身份、split、时间戳、目标数量与完整覆盖验证。不得将文件存在直接提升为官方protocol已验证。
4. GPU预算是单设备历史墙钟/占用时间的规划锚点。独立审计脚本中`NewGPUJobsExecuted=0`指该纯metadata脚本没有启动GPU任务；整个Stage14B允许且正在运行的是已登记三个匹配排序头，HiVT重训仍为0。

10. 核心统计量
============================================================

对每个预定义 group
统计：

A_raw =
mean(|b_A|)

F_raw =
mean(|b_F|)

F_effective =
mean(|g*b_F|)

以及：

RawAmplification =

F_raw / (A_raw + 1e-8)

EffectiveRetention =

F_effective / (A_raw + 1e-8)

其中：

RawAmplification > 1

表示 Stage4F relation branch
学到了比 Stage4A 更大的 raw bias。

EffectiveRetention ≈ 1

表示虽然有 gate，
真正进入 attention 的扰动仍接近 Stage4A。

============================================================
11. Gate-adjusted compensation index
============================================================

同一组内计算：

EdgeWeightedGateMean =

按该组所有 edge-layer-head observation
对应 target gate 的平均值。

然后：

ExpectedRetentionWithoutCompensation
≈
EdgeWeightedGateMean

定义描述性：

CompensationIndex =

EffectiveRetention
/
(EdgeWeightedGateMean + 1e-8)

解释：

≈1：
没有明显 amplitude compensation

明显 >1：
raw relation magnitude
在补偿 gate shrinkage

明显 <1：
relation branch 本身也减弱

注意：

这是描述性指标。

不要人为规定显著性阈值。

6. 有向 Type Pair 定义
============================================================

PyG 当前 edge convention：

source = edge_index[0] = j
target = edge_index[1] = i

因此定义：

pair_id =
3 * target_type + source_type

即：

pair_id =
3*c_i + c_j

其中：

vehicle = 0
pedestrian = 1
bicycle = 2

必须保存映射：

0 = V <- V
1 = V <- P
2 = V <- B

3 = P <- V
4 = P <- P
5 = P <- B

6 = B <- V
7 = B <- P
8 = B <- B

论文符号可理解为：

j -> i

禁止方向写反。

写 unit test 验证。

============================================================
7. Relation Feature
============================================================

不要构建复杂动态图。

使用当前 GlobalInteractor 已经具有的关系信息：

当前时刻相对位置：
Δp_ij

当前相对航向：
Δθ_ij

再加入：

有向 type-pair embedding。

定义：

E_pair(c_i,c_j)
∈ R^16

pair embedding：

nn.Embedding(
    num_embeddings=9,
    embedding_dim=16
)

Relation feature：

r_ij =
[
    E_pair(c_i,c_j),
    Δx_ij / R,
    Δy_ij / R,
    cos(Δθ_ij),
    sin(Δθ_ij)
]

其中：

R = local_radius = 50 m

所以输入维度：

16 + 2 + 2 = 20

不要加入：

TTC
地图关系
未来轨迹
GT
intent
visibility
人工 risk label

本轮只测类型条件关系。

8. Relation Bias Network
============================================================

使用一个很小的共享 MLP：

当前：

所以最后输出：

24维

reshape：

[E, 3, 8]

表示：

每条 interaction edge
每个 GlobalInteractor layer
每个 attention head

一个 scalar bias。

记：

b_ij^(l,h)

============================================================
9. Attention 修改
============================================================

当前 HiVT：

score_ij^(h)
=
q_i^h · (k_j^h + k_edge^h)
/
sqrt(d_h)

Stage4A：

score_ij^(l,h)
=
q_i^h · (k_j^h + k_edge^h)
/
sqrt(d_h)
+
b_ij^(l,h)

然后保持：

alpha_ij =
softmax_j(score_ij)

后续 value aggregation 完全不改。

注意：

relation bias 加在 softmax 之前。

禁止：

直接乘 attention
修改 value

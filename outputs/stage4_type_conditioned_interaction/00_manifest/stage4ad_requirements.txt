============================================================
9. Attention Entropy
============================================================

必须比较加 bias 前后 attention distribution。

对于每一个：

target node
layer
head

计算原始：

alpha_base =
softmax(base_logit)

和：

alpha_final =
softmax(base_logit + bias)

entropy：

H =
-sum_j alpha_j log(alpha_j)

记录：

H_base
H_final

Delta_H =
H_final - H_base

按：

Vehicle target
Pedestrian target
Bicycle target

以及 directed pair context

汇总：

mean
median
p10
p90

解释：

Delta_H < 0：
attention 更集中

Delta_H > 0：
attention 更分散

不要直接解释成“更好/更坏”。

20. 诊断结论规则
============================================================

输出：

09_reports/
stage4ad_relation_bias_diagnostic_report.md

最终只允许以下三种结论：

CASE A：

Evidence supports over-strong bias

条件：

Pedestrian 的相对 bias scale /
attention shift 明显高，

且 lambda < 1 时
Pedestrian FDE 有一致恢复趋势，
同时 Vehicle 优势没有完全消失。

推荐下一模型：

bounded target-type adaptive residual gate

CASE B：

Mixed evidence

尺度或 attention shift 存在差异，
但 lambda sensitivity 不形成清晰趋势。

推荐：

不要直接认定 bias 过强，
进一步分析 representation / class imbalance。

CASE C：

No evidence for over-strong bias

Pedestrian 与 Vehicle 的 bias/base scale
没有实质区别，

而减小 lambda
也不能恢复 pedestrian。

推荐：

放弃“只限制 bias 强度”的修改方向，
重新设计 interaction mechanism。

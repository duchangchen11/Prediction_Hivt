9. 第一项模型实验：
Tiny-set Overfit
==================================================

这是硬性要求。

不要直接训练整个 mini。

首先选择：

约 16～64 个训练窗口

vehicle only。

使用 HiVT：

K = 原始 HiVT 默认模式数
如果原实现就是 K=6，则保留 K=6。

训练足够多 epoch，
目标不是泛化，
而是证明模型能记住小数据。

要求记录：

train loss
regression loss
classification/mode loss
minADE
minFDE

预期：

loss 明显下降；

训练集 minADE/minFDE 明显下降；

轨迹从随机状态变成合理形状。

如果 tiny-set 都不能明显 overfit：

立即停止。

优先排查：

- tensor shape
- coordinate system
- target normalization
- rotation
- masks
- multimodal loss
- decoder output scale
- learning rate
- map indexing

禁止通过加入创新模块“解决”。

保存：

outputs/stage2/tiny_overfit/

包括：

config.yaml
metrics.json
training_curve.csv
checkpoint
prediction figures

至少画：

5 个预测案例。
